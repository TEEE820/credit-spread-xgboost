# 设计文档：可解释机器学习框架下中国信用利差的非线性决定机制与预测

## 1. 项目概述

- **项目定位**：以实务/普刊发表为目标的实证研究，同时截取核心内容满足《固定收益证券》课程大作业要求
- **硬性约束**：2027 年 1 月前拿到**录用通知**（非见刊）
- **指导老师**：华南师范大学国际商学院马赞军老师（金融实务导向，选题契合）
- **团队分工**：用户负责论文写作与投稿；AI 编程手负责全部数据获取、特征工程、建模、预测与图表产出

## 2. 研究设计

### 2.1 研究对象
- **目标变量**：信用利差 \(CS_t = Y_{credit,t} - Y_{treasury,t}\)
- **品种与评级**：中债中短期票据收益率曲线，AAA / AA+ / AA 三档评级
- **期限**：3 年期为主，5 年期做稳健性检验
- **频率**：周频（宏观月频变量前向填充对齐）
- **样本区间**：2015 年初 ～ 2026 年中，约 600 周 × 3 评级 ≈ 1700+ 观测

### 2.2 特征体系
| 组别 | 变量 | 说明 |
|------|------|------|
| 宏观 | CPI、PPI 同比、PMI、社融存量同比、M2 同比、工业增加值 | 月频→周频对齐，使用时点对齐避免未来函数 |
| 市场 | 沪深300 周收益率、周波动率、10Y 国债收益率水平、期限利差(10Y−1Y) | 日频数据构造 |
| 流动性 | R007 或 SHIBOR 3M | 待实测可用性，备选 DR007 |
| 自回归 | 利差滞后 1～4 周 | 时序建模关键特征 |

### 2.3 模型与验证
- **主模型**：XGBoost（GridSearchCV 超参调优）
- **基准对照**：OLS、随机森林
- **解释方法**：SHAP 全局重要性、依赖图、评级间敏感度对比
- **预测验证**：expanding-window 滚动，向前 1 周预测，RMSE/MAE/方向准确率，对比随机游走基准

### 2.4 学术创新点（投稿卖点）
1. 非线性机制刻画：SHAP 依赖图揭示因子阈值效应
2. 时变特征重要性：滚动 SHAP 刻画市场状态切换
3. 评级异质性：量化对比 AAA/AA+/AA 对风险因子的敏感度差异
4. 样本外预测：XGBoost 与传统模型滚动对比

### 2.5 稳健性检验（审稿修改阶段按需补充）
- 期限：3Y → 5Y
- 频率：周频 → 月频
- 模型：LightGBM 加入对比
- 预测窗口：h=1 → h=4
- 分样本：2015-2019 / 2020-2026

## 3. 数据方案

- **来源**：akshare 开源接口（`bond_china_yield` 获取中债多评级曲线，宏观接口获取经济变量）
- **已确认**：`bond_china_yield` 支持国债+中短期票据(AAA)等多评级曲线，单次请求限一年内，循环拉取
- **待实测**：AA+/AA 曲线是否在接口返回中、R007/SHIBOR 接口可用性
- **风险预案**：接口失效时改用 tushare 或直接按中国债券信息网官方接口协议爬取

## 5. 论文产出

- **期刊论文**（约 10000-12000 字，实务期刊风格）：引言→文献综述→数据与方法→实证（非线性+时变+异质性+预测）→实务启示→结论
- **课程作业**（5000-10000 字）：按课程七段结构（研究背景→文献综述→研究过程→数据获取处理→具体分析→结论→参考文献），截取核心实证

## 6. 时间线（倒排，极限节奏）

| 时间 | 里程碑 |
|------|--------|
| 第 1 周（现在~10/6） | 环境搭建、接口实测、全部数据入库 |

## 7. 风险与应对

| 风险 | 应对 |
|------|------|
| akshare 接口失效 | tushare 备选 / 直连中债官网接口 |
| 审稿周期超预期 | 期刊备选名单按优先级排序，被拒后依次改投（遵守学术规范，不并行一稿多投） |
| 论文写作拖慢进度 | AI 直接起草实证部分+提供写作框架，用户只做改写与润色 |
| AA+/AA 曲线数据缺失 | 降级为 AAA 单评级 + 期限维度对比，创新点 3 改用期限异质性 |
